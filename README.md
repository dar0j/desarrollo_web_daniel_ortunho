# Tarea 4 - Desarrollo Web

## Descripción
Esta tarea consiste en añadir la funcionalidad de evaluar actividades realizadas de las tareas implementadas anteriores.

Usa el framework SpringBoot (MVC) que está en Java, junto con una base de datos MySQL (MariaDB en Linux Manjaro que es mi notebook) y JPA para abstraer operaciones de base de datos con Thymeleaf para renderizar dinámicamente contenido reutilizable.
